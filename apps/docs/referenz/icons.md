# Icons

Icons sind einfarbige Symbole im 24×24-Raster. Das Theme färbt sie in der Textfarbe der
Kategorie. Du setzt sie nur in Templates: `icon <name>` (bzw. `icon none`, um ein geerbtes Icon
zu entfernen). Diese Seite wird bei jedem Build aus `library/icons/` erzeugt.
