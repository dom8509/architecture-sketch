# Anleitungen

Jede Anleitung löst eine Aufgabe von Anfang bis Ende. Grundlagen vermittelt der
[Schnellstart](/einstieg/schnellstart); alle Details stehen in der [Referenz](/referenz/sprache).

## Diagramme modellieren

| Anleitung | Du lernst … |
|-----------|-------------|
| [Pins und Verbindungen](./pins-und-verbindungen) | Pins deklarieren, auf Seiten legen, Signalarten und Pfeilrichtungen wählen |
| [Zonen und Systeme](./zonen-und-systeme) | Diagramme in Bänder gliedern und Steuergeräte umrahmen |
| [Layout steuern](./layout) | Flussrichtung, Grid, überspannende Zellen und Hints |
| [Präsentationssichten](./praesentation) | Pins ausblenden, Mehrfachelemente stapeln, Beamer-Theme |
| [Eigene Templates](./templates) | eigene Bausteine mit `define` und `extends` anlegen |
