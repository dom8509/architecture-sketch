# Themes

Themes are design tokens: colors, type, line weights and spacing. The language itself knows no
pixels and no colors — the theme decides. You pick one with `theme <name>` in the architecture,
through the theme selector of the web app, through the Obsidian setting or with
`sysarch render --theme`.

This holds for every theme: color is never the only carrier of information. Signal groups
always differ in line weight, dash pattern or end marker as well.

The images show the [Zonal ECU](./examples#zonal-ecu) example and are re-rendered on every
build.
