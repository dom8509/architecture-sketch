# Library

The standard library is loaded before every document. It is itself written in sysarch:
[`library/automotive.archlib`](https://github.com/dom8509/sysarch/blob/main/library/automotive.archlib).
This page is generated from the library on every build.

Usage: `component <id>: <template>`. You derive your own building blocks with `extends` — see
[Custom templates](/guides/templates). In Obsidian, **sysarch: Show library** shows the same
templates in the sidebar.
